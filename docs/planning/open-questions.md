## ✅ 확정 (2026-08-26)

| ID | 결정 |
|----|------|
| **Q1** | 실물만 선생님에게 전달. 앱 기부 신청 없음. 선생님이 대시보드에서 상품 등록 + 포인트 수동 지급 |
| **Q2** | 1·2·3학년 모두 사용. 학번 = 학년 1자리 + 반 2자리 + 번호 2자리 (`10101`, `20101`, `30101`). **18반은 전교 반 수 합계** (한 학년에 18반이 아님) |
| **Q3** | 엑셀/CSV로 학번·이름 등 일괄 등록. 한 명씩 입력은 1차 없음 |
| **Q4** | 학번 + 이름 확인 후 학생이 새 비밀번호 설정. 관리자 초기화는 1차 없음 |
| **Q5** | 별도 이메일이 아님. **특정 학번에 관리자 역할.** 관리자도 학번으로 로그인. 누구인지는 CSV `role` 컬럼 |
| **Q6** | **둘 다 따로.** 컨디션(상/중/하) + 판매 상태(판매중/예약/완료) |
| **Q7** | 기본 잔액 0. 기부 받을 때마다 해당 학생 **수동 지급** + 행사 때 **여러 명 일괄 지급** |
| **Q8** | Phase 3. 토스페이먼츠. 학생 플랫폼 수수료 0. **PG 수수료는 우리가 흡수.** 1원=1P 등 환산은 나중에 |
| **Q9** | **수령 전에** 학생이 취소하면 포인트 환급. 실물은 교실 또는 선생님에게 수령 |
| **Q10** | 먼저 누른 사람만 성공, 나머지는 품절. 대기/예약 없음 |
| **Q11** | 지금은 **우리 학교 파일럿.** 이후 학교 단위 구독 유료화 |
| **Q12** | 배포는 하되 **교내·휴대폰에서만** 쓰면 됨. 검색 노출 필요 없음 |
