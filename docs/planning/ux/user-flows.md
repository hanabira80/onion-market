# 사용자 흐름 (User Flows)

> **양파**

---

## 1. 첫 로그인 (비밀번호 설정)

```mermaid
flowchart TD
    A[로그인 화면] --> B[학번 입력]
    B --> C{명단에 있는가}
    C -->|없음| D[오류. 가입 없음]
    C -->|있음| E[이름 표시]
    E --> F{본인 확인}
    F -->|아니오| A
    F -->|예| G{비밀번호 이미 있음}
    G -->|없음| H[새 비밀번호 설정]
    G -->|있음| I[비밀번호 입력]
    H --> J[쇼핑몰 홈]
    I -->|맞음| J
    I -->|틀림| I
```

학번 5자리: 학년 + 반 2자리 + 번호 2자리. 찾기: 학번 → 이름 확인 → 새 비밀번호.

---

## 2. 포인트로 굿즈 구매 · 수령 전 취소

```mermaid
flowchart TD
    A[상품 목록] --> B[상세]
    B --> C{찜 또는 구매}
    C -->|찜| D[찜 목록]
    C -->|구매| E{잔액·수량·선점}
    E -->|실패| F[잔액 부족 또는 품절]
    E -->|성공| G[수령 대기]
    G --> H{수령 전 취소?}
    H -->|예| I[포인트·재고 복구]
    H -->|교실에서 수령| J[관리자가 수령 완료]
```

동시에 누르면 먼저 성공한 사람만 사고 나머지는 품절이다.

---

## 3. 실물 기부 → 관리자 등록 (Q1)

```mermaid
flowchart TD
    A[학생: 관심 떨어진 굿즈] --> B[선생님에게 실물 전달]
    B --> C[관리자 학번으로 로그인]
    C --> D[상품 등록]
    C --> E[해당 학생 포인트 지급]
    D --> F[몰에 상품 표시]
    E --> G[학생 잔액 증가]
    G --> H[원하는 굿즈 구매]
```

앱 기부 신청서는 없다. 행사 때는 여러 명에게 포인트를 한 번에 줄 수 있다.

---

## 4. 관리자 상품 업로드

```mermaid
flowchart TD
    A[학번 로그인 role=admin] --> B[/admin]
    B --> C[새 상품]
    C --> D[사진 / 컨디션 / 판매상태 / 포인트 / 수량 / 카테고리]
    D --> E[학생 몰 노출]
```
