# 나중에 할 일

지금 로드맵에서 뺀 일. 착수할 때 이 문서를 다시 로드맵으로 올린다.

---

## Phase 3 — 토스 포인트 충전

**상태:** 나중

**목표:** 토스페이먼츠로 충전. 학생에게 플랫폼 수수료 없음. **PG 수수료는 우리가 흡수.**

**비범위 (Out):** 다른 PG, 구독, 환산 비율은 착수 시 확정

**완료 기준:**

- [ ] 학생이 토스로 충전하면 포인트가 오른다
- [ ] 학생 화면에 마켓 수수료가 없다
- [ ] 충전 최소 금액·1원당 포인트는 착수 시 정한다

**착수 전 정할 것:** 충전 최소 금액, 1원당 포인트 환산 (open-questions의 Phase 3 항목)

**의존:** Phase 1 학급 마켓이 끝난 뒤. Phase 2와는 따로 진행할 수 있다.

---

## Phase 4 — 학교 행사 유료화

**상태:** 나중

**목표:** 지금은 **우리 학교 파일럿**. 이후 학교 단위 **구독**으로 다른 학교 선생님에게 판다.

**비범위 (Out):** 1차 멀티테넌시 없음. 행사 건당 과금은 채택하지 않음.

**의존:** Phase 1 학급 마켓이 끝난 뒤. 파일럿 운영 후에 착수한다.
