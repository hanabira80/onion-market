# PRD-005: 앱 기부 신청 (보류)

| 항목 | 내용 |
|------|------|
| Phase | 2 (착수 안 함) |
| 상태 | 보류 |
| 작성일 | 2026-08-26 |

---

## 1. 목표

Q1 확정: **앱에서 기부 신청을 받지 않는다.** 학생은 실물을 선생님에게 주고, 관리자가 Phase 1 대시보드에서 상품 등록 + 포인트를 지급한다.

이 문서는 나중에 “학생도 앱으로 신청하고 싶다”가 나올 때만 연다.

---

## 2. 현재 루프 (Phase 1으로 충족)

1. 학생: 관심 떨어진 굿즈를 선생님에게 전달
2. 관리자: `/admin/products/new` + `/admin/points`
3. 학생: 몰에서 원하는 굿즈를 포인트로 구매
