# PRD-005: 실물 기부

| 항목 | 내용 |
|------|------|
| Phase | 2 |
| 상태 | 완료 |
| 작성일 | 2026-08-26 |
| 확정 | 2026-10-12 |

---

## 1. 목표

학생은 관심 떨어진 굿즈를 선생님에게 **실물로** 준다.  
관리자가 지금 앱에서 그 학생에게 포인트를 주고, 상품 사진과 판매 정보를 올린다.

학생용 기부 신청 화면은 만들지 않는다.

---

## 2. 루프

1. 학생: 물건을 선생님에게 전달
2. 관리자: `/admin/points`에서 해당 학생 포인트 지급
3. 관리자: `/admin/products/new`에서 사진·컨디션·판매 상태·구매 포인트·수량·카테고리 등록
4. 학생: 몰에서 원하는 굿즈를 포인트로 구매

---

## 3. 범위

### In Scope

| 기능 | 설명 |
|------|------|
| 실물 수령 | 앱 밖. 선생님·관리자가 물건을 받는다 |
| 포인트 지급 | 기존 `/admin/points`. 개별·일괄 |
| 상품 등록 | 기존 `/admin/products/new`. 사진과 판매 정보는 관리자만 |

### Out of Scope

| 기능 | 사유 |
|------|------|
| `/donate` | 학생 신청 없음 |
| `/admin/donations` 검수 큐 | 실물 확인 후 관리자가 직접 등록·지급 |

---

## 4. 화면·URL

새 URL 없음. Phase 1 관리 화면을 그대로 쓴다.

| URL | 하는 일 |
|-----|---------|
| `/admin/points` | 기부한 학생에게 포인트 |
| `/admin/products/new` | 사진·판매 정보 등록 |
| `/admin/products/[id]` | 등록한 상품 수정 |

---

## 5. 완료 기준

- [x] 학생이 앱으로 기부를 신청하는 화면이 없다
- [x] 관리자만 포인트를 지급할 수 있다
- [x] 관리자만 상품 사진과 판매 정보를 올릴 수 있다

---

## 6. 티켓 분할

새 화면 없음. Phase 1의 포인트 지급·상품 등록으로 끝.
