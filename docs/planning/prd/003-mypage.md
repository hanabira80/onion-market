## 1. 목표

학생이 **내 포인트, 산 물건, 찜한 물건**을 한곳에서 본다.

---

## 2. 사용자 시나리오

### US-1: 잔액 확인

> 학생으로서, 지금 쓸 수 있는 포인트를 알고 싶다.

1. 헤더 또는 `/me`에서 현재 포인트를 본다
2. 숫자는 서버 잔액과 같다

### US-2: 구매 목록

> 학생으로서, 내가 포인트로 산 굿즈를 확인하고 싶다.

1. `/me/orders`에서 구매일, 상품명, 사진, 사용한 포인트, 수량(1이 기본)
2. 상품 상세로 이동 (품절이어도 기록은 남김)
3. `수령 대기`면 취소 가능. 취소 시 포인트·재고 복구

### US-3: 찜 목록

> 학생으로서, 찜해 둔 굿즈만 모아서 보고 다시 사고 싶다.

1. `/me/wishlist`에서 찜한 상품 카드
2. 찜 해제, 상세로 이동, 품절이면 표시

---

## 3. 범위

### In Scope

| 기능 | 설명 |
|------|------|
| 포인트 표시 | `/me` 상단 + 가능하면 헤더 |
| 구매 목록 | 내 주문만. 상태: 수령 대기 / 수령 완료 / 취소 |
| 수령 전 취소 | 포인트 환급 + 재고 복구 |
| 찜 목록 | 내 찜만. 상세/해제 가능 |
| 로그아웃 진입점 | 마이페이지 또는 헤더 |

### Out of Scope

| 기능 | 사유 |
|------|------|
| 프로필 사진·닉네임 변경 | 이름은 명단 기준. 요청 시 추가 |
| 비밀번호 변경 | 로그인의 찾기와 별도. 있으면 `/me/password`로 나중에 |
| 기부 내역 | 앱 기부 없음 (Q1) |
| 충전 내역 | Phase 3 |
| 수령 후 취소 | Q9: 받기 전만 |

## 5. 완료 기준 (Definition of Done)

- [ ] 로그인한 학생만 `/me*`에 들어간다
- [ ] 포인트가 실제 잔액과 같다
- [ ] 구매한 상품만 구매 목록에 있다
- [ ] 찜한 상품만 찜 목록에 있고, 해제하면 목록에서 사라진다
- [ ] 다른 학생의 구매·찜이 보이지 않는다
- [ ] 수령 전 취소 시 포인트와 재고가 돌아온다
- [ ] 수령 완료 주문은 취소할 수 없다
